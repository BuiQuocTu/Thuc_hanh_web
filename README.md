## Tính năng đã hoàn thành
- Layout Flexbox và Grid đúng tiêu chuẩn semantics.
- Responsive mobile-first và hỗ trợ Dark mode qua cặp Token.
- Tách biệt module JS xử lý menu mobile, theme toggle.
- Quản lý state render từ file dữ liệu JSON `data/records.json`.

## 3 điều sẽ làm lại nếu có thêm thời gian
1. Viết thêm các bộ test tự động (Unit test) cho mô hình state -> render.
2. Tối ưu file CSS bundle nhỏ gọn hơn bằng PurgeCSS nâng cao.
3. Bổ sung animation trượt hiệu ứng nâng cao cho Slider.
